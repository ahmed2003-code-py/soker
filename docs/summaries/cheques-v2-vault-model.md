### ✅ Cheques — نموذج «خزنة الشيكات» (v2) للشيكات الواردة

نموذج محاسبي جديد للشيكات **الواردة** فقط، معزول بعلامة نسخة (`accountingVersion`): الشيكات القديمة = 1 (منطقها ثابت)، أي شيك جديد = 2. الصادرة تتبع منطقها الحالي دائماً (بوابة الاتجاه).

- **دورة الحياة (v2):** مسجّل → {مودع / مظهّر / محصّل} → (مرتد / ملغي).
- **الآثار المحاسبية (idempotent — عكس/إعادة تطبيق):**
  - **مسجّل:** دين العميل −القيمة + دخول خزنة الشيكات (خزنة الشيكات مُشتقّة = Σ الشيكات المسجّلة، منفصلة عن إجمالي الخزنة).
  - **مودع (بنك):** خزنة الشيكات −، البنك المختار +. دين العميل ثابت.
  - **مظهّر (مورد):** خزنة الشيكات −، مديونية المورد −. دين العميل ثابت.
  - **محصّل (نقدي):** خزنة الشيكات −، النقدية +. (نهاية الدورة)
  - **مرتد (حالتان تلقائياً):** يعكس آخر أثر ويرجّع **دين العميل**. لو كان مودعاً/محصّلاً → يعكس البنك/النقدية؛ لو كان مظهّراً → يعكس التظهير فيرجع **مستحق المورد** أيضاً. + تنبيه بشيكات مرتدة تحتاج تسوية.
  - **ملغي:** يعكس كل الأثر + يحفظ **سبب الإلغاء وتاريخه** بدون حذف السجل.
- **القرارات (بموافقة المالك):** دين العميل يقلّ وقت التسجيل فوراً · خزنة الشيكات منفصلة عن إجمالي الكاش · الصادرة بلا تغيير · النموذج الجديد للشيكات الجاية فقط.
